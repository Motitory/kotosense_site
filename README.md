# kotosense_site

[KotoSense](https://github.com/Motitory/kotosense) 앱의 공개 페이지. 스토어 심사에 필요한
**개인정보처리방침·이용약관 URL**을 제공하기 위한 정적 사이트다.

| 파일 | 주소 | 쓰는 곳 |
|---|---|---|
| `index.html` | `/kotosense_site/` | App Store·Play의 지원(Support) URL |
| `privacy.html` | `/kotosense_site/privacy.html` | 개인정보처리방침 URL(필수) |
| `terms.html` | `/kotosense_site/terms.html` | 이용약관 |

## 고칠 때

원본은 앱 저장소의 `docs/site/`에 있다. 거기서 고치고 이 저장소로 복사해 올린다.
문서 내용(한국어 본문)은 앱 저장소의 `docs/PRIVACY.md`·`docs/TERMS.md`와 같은 내용을 담는다.

앱의 스토어 등록 정보에 적은 **주소는 바꾸기 번거롭다**(App Store는 다음 앱 버전과 함께 반영된다).
주소를 옮기지 말고 이 저장소의 내용을 고치는 쪽으로 유지한다.

`.nojekyll`은 GitHub Pages가 파일을 그대로 내보내게 하는 표시다.
